## 二、安装（1 分钟）

1. 双击下载好的 `.pkg` → 一路「继续」直到完成
2. 从**启动台**打开「微信开发者工具」
   - 若弹「无法打开，因为来自身份不明的开发者」→ 到「访达 → 应用程序」，**右键**该 App 选「打开」
3. 用**你自己的微信**扫码登录（不需要企业账号）

---

## 三、导入项目（30 秒）

1. 点左上角 **「+」或「导入项目」**
2. 目录选这个（直接复制路径，`⇧⌘G` 粘贴）：
   ```
   /Users/jeremysmac/WorkBuddy/2026-08-27-21-15-16/garage-vite/miniprogram
   ```
3. AppID 填：`touristappid`（游客模式，**工程里已经配好了**）
   - 云开发选「不使用」
4. 点「导入」→ 等它自动编译

> 现在还没注册企业小程序，所以先用游客 AppID 看效果。等有了真实 AppID，再把 `project.config.json` 里的 `appid` 换掉即可。

## 四、跑起来看效果

模拟器会自动编译并显示你的小程序：

- **首页 / 车库 / 我的**：三个原生页面，底部有 tabBar，配色是黑底霓虹青
- 进「车库」点任意方案卡片 → 跳到 **editor 页**，这里就是 `<web-view>` 承载的完整 3D 应用

你现在**能看到**的：
- ✅ 小程序完整外壳 + tabBar + 原生页面
- ✅ web-view 里加载出真实的 3D 改装站点（地址已指向线上 `inspire-car.fly.dev`）
- ✅ 在 web-view 里手动登录后可以正常玩 3D 改装

你现在**看不到**的（按先后顺序来，别急）：
- ❌ 免密自动登录（还缺小程序 AppID/AppSecret）
- ❌ 微信支付、分享到朋友圈（需真实 AppID + 微信认证 + 备案域名）

## 五、排错清单

| 现象 | 解决 |
|---|---|
| web-view 白屏 / 提示「非业务域名」 | 「详情 → 本地设置」勾上 **「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」** |
| 模拟器空白、样式全无 | 「详情 → 本地设置」确认勾了 **ES6 转 ES5** 和 **增强编译**（工程已配，旧版工具会覆盖） |
| 提示「不是管理员/没有权限」 | 需要在 mp 后台把自己的微信号加为该小程序的开发者（有了真实 AppID 后才有这个后台） |
| 扫码预览失败 | 游客 AppID 不支持预览/上传，必须换成真实 AppID |
| 安装时报磁盘不足 | 先清废纸篓、下载文件夹，腾出 8~10 GB |

## 六、下一步顺序（按时间紧迫排序）

1. **ICP 备案**：买内地服务器 + 提交备案（7~20 天，最慢，**最该先启动**）
2. **注册小程序**：企业/个体户主体 → 微信认证 ¥300/年 → 拿到 AppID + AppSecret
3. **我来接通登录**：把 AppID/AppSecret 配到 Fly secrets，自动登录即生效
4. **迁移到国内服务器** + 配置业务域名校验文件（`public/.well-known/`）
5. **微信支付商户号** + 原生支付页（这是盈利那步）

## 附：本项目中我改过的唯一文件

`miniprogram/app.js` —— 里面只有这三行配置会随你的域名变化，其余代码都不用动：

```js
API_BASE:   'https://inspire-car.fly.dev',  // 后端
WEB_BASE:   'https://inspire-car.fly.dev',  // 承载 3D 的站点
STUDIO_PATH: '/',
```

⚠️ `STUDIO_PATH` 暂时**必须是 `/`**：线上和本地的未知子路径都返回 502（静态回落有 bug），
等修好后再改深链。详见代码内注释。
