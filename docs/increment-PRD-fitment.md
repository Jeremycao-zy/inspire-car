## 1. 调研结论：真实的改装物理规则

> 所有关键数值均标注来源。来源冲突处已列出并说明采信理由。未查到确切数据的，明确标注"未查到 / 建议值 + 依据"，**不编造**。

### 1.1 轮胎规格解码

`225/45R17 94W` 每一位：

| 位 | 含义 |
|---|---|
| `225` | 断面宽 Section Width，mm（胎侧到胎侧最宽处，**不是**胎面宽、**不是**轮辋宽） |
| `45` | 扁平比 Aspect Ratio，% —— 胎壁高 = 断面宽 × 45% |
| `R` | Radial 子午线结构 |
| `17` | 轮辋直径，**英寸** |
| `94W` | 载重指数 / 速度等级（不影响尺寸） |

**外径公式（本次统一口径，mm）：**

```
胎壁高 SW = 断面宽 W × 扁平比 A / 100
外径   OD = 轮辋直径 D(in) × 25.4 + 2 × SW
          = D × 25.4 + 2 × W × A / 100
```

验证 `225/45R17`：17×25.4 + 2×225×0.45 = 431.8 + 202.5 = **634.3mm（24.97"）** ✓

> 25.4 mm/inch 是定义值（精确），无误差。

### 1.2 外径偏差容许范围

| 来源 | 说法 |
|---|---|
| shop.warehousetire.net/tire-tech | "Keep overall diameter within **3%** of original for accurate speedometer" |
| tiresizeguide.com | "you can replace the tire within a **3% difference** in tire diameter of the OEM tire size" |
| calculatorsandmore.com | "Most states allow up to 3% error without inspection failure" |
| rimlist.com/plus-sizing-guide | ±3% 为兼容筛选线，并额外标注 "Best Fit" = **±1%** |
| automotto.com | 同上 |

**采信：**
- **硬红线 ±3%**（超速表 / ABS / ESP 轮速信号失真，多来源一致）
- **推荐目标 ±1.5%**
- **理想 ±0.5%**（原厂 staggered 实测水平，见 1.9）

外径偏差 → 时速表误差（真实 100 km/h）：+1% → 表显 99.0；+2% → 98.0；+3% → 97.1；+5% → 95.2。

### 1.4 J 值（轮辋宽度）

**定义**（多来源一致）：
- 数字 = 轮辋宽度，**英寸**；`1J = 25.4mm`
- 字母 `J` = 轮辋凸缘（flange）的形状与高度代号（C 最低、J 最常见、K 最高）
- **J 值 = 两个胎圈座（bead seat）之间的距离**（ISO 5775 / ETRTO）
- **轮辋名义直径 = 胎圈座直径，不是外缘直径** ← 对 3D 缩放很关键（见 §5.7）

**⚠️ 来源冲突：J ↔ 胎宽对照表有两个版本**

| J 值 | 版本 A（tyaward，线性自洽）最小/推荐/最大 | 版本 B（chinanews / 搜狗百科 / dhwheel，国内流传最广） |
|---|---|---|
| 8.0J | 225 / 235 / 245 | 225 / 235 / 245 |
| 8.5J | 235 / 245 / 255 | 235 / 245 / 255 |
| 9.0J | 245 / 255 / 265 | 245 / 255 / 265 |
| **9.5J** | **255 / 265 / 275** | **265 / 275 / 285** ← 跳档 |
| **10.0J** | **265 / 275 / 285** | **295 / 305 / 315** ← 跳档 |
| 10.5J | 275 / 285 / 295 | 305 / 315 / 325 |

版本 B 内部不自洽（9.5J 上限 285 → 10.0J 下限 295 出现断层）。

**但 TRA 实测数据站在版本 B 一边：**
- `285/35R18` 批准轮辋 **9.5–11"**
- `285/30R19` 批准轮辋 **9.5–10.5"**
- R230 原厂后轮就是 **9.5J + 285 胎** —— 版本 A 会把原厂配置判为"超上限"

**采信方案**：以 **TRA 批准范围为主（绿灯）**，版本 A 的"推荐值"降级为**最佳值提示**。用比值统一表述 + 表格给出可查区间。

**比值定义：** `ratio = 胎宽 mm / (J × 25.4)`

实测交叉验证：

|---|---|---|---|

|---|---|---|---|
| 香蕉胎（辋太窄） | > 1.32 | 胎壁支撑不足，过弯折胎、转向迟钝 | 🔴 |

**装窄/装宽的后果**（tyaward、mechanicscalculator 一致）：
- **辋太窄**：胎壁外鼓成"香蕉胎/甜甜圈"，过弯折胎、转向迟钝、路感模糊、激烈驾驶易过热
- **辋太宽**：胎壁被拉伸，胎侧保护下降、接地形状改变、更易受冲击损伤

### 1.5 ET / Offset（偏距）

**定义**：`ET = Einpresstiefe（德语"压入深度"）` = 轮辋中心线到安装面（与轮毂法兰贴合面）的距离，mm。
- **正 ET**：安装面在中心线外侧 → 车轮内收
- **ET 0**：安装面 = 中心线
- **负 ET**：安装面在中心线内侧 → 车轮外凸

**量化关系（本次采用）：**

```
单侧外移量 Δouter = (W_new/2 − ET_new) − (W_old/2 − ET_old)     [mm]
轮距变化   Δtrack = 2 × Δouter
```

推论（各来源一致）：
- **ET 每减小 1mm → 车轮外移 1mm，轮距 +2mm**
- **J 每增大 1 inch（25.4mm）→ 单侧外缘外移 12.7mm**（内缘同时内移 12.7mm）
- **垫片 t mm ⇔ ET 减小 t mm**（`ET_eff = ET − t`）

**安全区间（冲突与采信）：**

| 偏移幅度 | oemwheelshop | calculatorcove | **采信** |
|---|---|---|---|
| ±5mm | "very safe" | "✅ Safe" | 🟢 无风险 |
| ±10mm | "check clearance" | "✅ Usually safe" | 🟢 需检查间隙 |
| ±15mm | "significant handling changes, risk of rubbing / bearing wear" | "⚠️ Check clearance" | 🟡 检查 + 提示轴承 |
| ±20mm+ | "not recommended without suspension mods" | "⚠️ May need modifications" | 🟠 警告 |
| >±25mm | — | "significant accelerated bearing wear；>30mm 可能轴承早期失效" | 🔴 强警告 |

**其他影响**（engineerfix / oemwheelshop / calculatorcove 一致）：
- **Scrub radius**：ET 改变转向轴线与接地印痕中心的横向距离 → 转向变重、颠簸回弹（kickback）、制动跑偏。10mm 即可感知
- **轮拱间隙**：ET 过小 → 蹭轮眉；ET 过大 → 蹭悬挂 / 制动卡钳
- **轴承负载**：力臂变长 → 轮毂轴承、球头、拉杆早期磨损

**OEM ET 常见范围**：紧凑/中型轿车 ET38–52；SUV/跨界 ET30–45；性能车/后驱 ET20–48；皮卡 ET15–30。

### 1.6 齐平度（Fitment）判定

**术语定义**（fmbwheels / kipardoracing / stanceauto 一致）：

| 术语 | 定义 |
|---|---|
| **Flush 齐平** | 轮辋/轮胎外缘与轮眉外缘**正好对齐**，不外凸也不内凹 |
| **Tuck 内凹** | 车轮完全在轮眉线以内 |
| **Poke 外凸** | 车轮/轮胎超出轮眉线 |
| **Stretch 蹦胎** | 轮胎窄于轮辋，胎壁被拉成 V 形。HellaFlush 标志性手段 |
| **Stance** | 低车身 + 负倾角的整体姿态（≠ Poke） |

**⚠️ 未查到权威的 mm 级量化阈值。** 所有来源均为定性描述。

**本次建议值（明确标注为建议值，非引用）**，依据：
1. "Flush" 语义是"平齐"，物理目标偏差 = 0
2. 对 26"（660mm）外径轮胎，±5mm ≈ 0.8%，是 45° 侧视下肉眼仍判读为"齐平"的宽容度
3. +12mm 沿用当前实现已有的"外凸"边界

| 判定 | 边界（mm） | 级别 |
|---|---|---|
| 过度内凹 Sunken | < −35 | 🔴 |
| 内凹 Tuck | −35 ~ −18 | 🟡 |
| 微凹 Mild tuck | −18 ~ −5 | 🟢 |
| **齐平 Flush** | **−5 ~ +5** | 🎯 🟢 |
| 微凸 Mild poke | +5 ~ +12 | 🟢 |
| 外凸 Poke | > +12 | 🔴（蹭胎 / 法规风险，需轮眉外扩） |

**关键修正 1：齐平度应以「轮胎胎侧外缘」为基准，不是轮辋外缘。**（当前 `wheelFit.js:151` 用 `rimHalf = j*25.4/2000`，与改装圈判读口径不符）

**关键修正 2：以「相对原厂外移量」作为主指标。** 绝对齐平度依赖翼子板基准标定，而 3D 包围盒半宽只是近似（见 1.9 后轴反例）。相对原厂的 `Δouter` 完全无歧义，也是改装圈真实交流方式（"比原厂外移 10mm 就齐平了"）。

**负倾角换齐平（真实做法的量化）：**
- 轮辋外缘顶部内移 ≈ `rimR × sin(θ)`。19" 轮辋（R=241mm）：**≈ 4.2mm/度**
- 轮胎胎侧顶部内移 ≈ `OD/2 × sin(θ)`。660mm 外径：**≈ 5.8mm/度**
- 接地印痕横移 ≈ `W × sin(θ)`。255mm 胎：**≈ 4.5mm/度**（mycalcbuddy："a 245mm tire by one degree shifts its contact point by roughly 4.3mm"，245×sin1°=4.28 ✓）

### 1.8 轮距（Track Width）与垫片

- **轮距定义**：同一轴上左右车轮**中心线**之间的距离
- **与 ET 换算**：`Δtrack = 2 × Δouter`
- **垫片**：`ET_eff = ET − t`；t mm 垫片 → 单侧外移 t mm → 轮距 +2t mm
- **垫片安全上限**：滑动式（无加长螺栓）5–10mm；螺栓固定式（hub-centric + 加长螺柱）25–30mm

## 3. P0-A：车轮切除的验收标准（"什么叫完全消失"）

### 3.1 现状嫌疑点（供工程师参考，不指定实现）

读码发现三处可能导致"切不干净 / 反而显现"的嫌疑点：

1. **`wheelCutout.js:150-152` 用三角形重心（centroid）做内外判定**。图生 3D 是单块粗网格（14.9 万面 / 整车），车轮区域单个三角形边长可能达 20–40mm。重心判定必然在切割边界留下或带走整块三角形 → **毛边残留**。
2. **切割半径 `radiusMul = 1.04`** 只比参数算出的轮胎外径大 4%。但模型里"原车轮"的实际尺寸由 `normalizeCar` 按车长 4.6m 归一推导，与参数算出的 R 未必一致；且车轮总成常包含轮毂内衬、刹车盘、悬挂臂，**这些在圆柱内但半径/轴向跨度未必被覆盖**。切掉外层胎面后露出内部轮毂/刹车盘 → 视觉上"反而像车轮了"。
3. **切除率指标口径错误**：`scripts/dryrun.mjs:154-155` 用 `removedTris / totalTris（整车面数）`。这个比值没有"正确答案"——车不同、轮子占比不同，4.3% 无法判断好坏。

### 3.2 验收指标（本次定义，可自动化）

以 `wheelFit.js:detectWheelCenters` 探测到的**原车轮**几何为基准构建**验收体**（不是用新轮毂参数）：

```
对每个探测到的原车轮 i（中心 c_i，半径 r_i，轮宽 w_i）：
  验收体_i = 圆柱{
    轴向 = Z，
    半径 = r_i × 1.15,
    轴向跨度 = [c_i.z − side × w_i/2 × 1.15,  c_i.z + side × w_i/2 × 1.15]
  }
  （w_i 探测不到时回退为 r_i × 0.45）
```

| 指标 | 定义 | 通过阈值 |
|---|---|---|
| **M1 残留率** | 切除后仍**可见**（在渲染索引中）且重心落在任一验收体内的三角形数 ÷ 切除前落在验收体内的三角形数 | **= 0%**（容差 ≤ 0.5%，仅允许边界三角形） |
| **M2 顶点级残留** | 切除后仍可见、且**三个顶点全部**落在验收体内的三角形数 | **= 0**（硬指标，无容差） |
| **M3 误伤率** | 被移除但**重心在验收体外**的三角形数 ÷ 整车三角形数 | **≤ 2%**（不能把车身切没） |
| **M4 单调性** | 切除后可见三角形数 vs 切除前 | **必须严格减少**；轮拱区域可见三角形数 ≤ 切除前的 30% |
| **M5 视觉验收** | 5 个标准机位（iso/side/front/rear/top）+ 4 个轮拱特写 | 人工 / 截图 diff：无原车轮胎面、轮辐、刹车盘、轮毂内衬残留 |

**M2 是关键**：直接对应"完全消失"的字面要求，且不受三角形大小影响。

### 3.3 反例验收（对应用户"反而显现出来了"）

| 指标 | 定义 | 通过阈值 |
|---|---|---|
| **N1 无新生遮挡** | 切除前后从 `side` 机位渲染，轮拱开口区域的深度复杂度 | 不得增加 |
| **N2 无破面** | 切除后翻转法线 / 非流形边 / 孤立顶点数量 | = 0（或不超过切除前的 1.2 倍） |
| **N3 内腔不裸奔** | 切除后从轮拱外侧能看到的"新暴露面" | 必须由新装配的轮毂+轮胎遮挡；无法遮挡时（如 ET 极大、轮辋极窄）需提示用户 |

```

OD (in) = OD(mm) / 25.4
```

### 4.2 Plus Sizing 联动规则（核心算法）

**规则 A（默认开启）：同胎宽下，轮辋直径 +1 inch ⇒ 扁平比 −5**

```
Δn = rimInch_new − rimInch_old            // 可为 ±0.5 / ±1
aspect_new = clamp( round(aspect_old − 5 × Δn), 25, 50 )
```

守恒精度见 §1.3 表。

**触底处理**：若 `aspect` 已到边界（25 或 50），不再联动，改为输出「外径偏差 X.X%」警告。

**档位命名**：以载入时的 OE 直径为 Plus 0，`rimInch − OE_rimInch` 即档位。

## 5. 参数联动规则（关键缺失项）

### 5.1 参数分类

| 类别 | 参数 | 行为 |
|---|---|---|
| **自由滑杆** | ET、倾角、轮距微调、轴位置 | 直接生效，**不改任何其他参数** |
| **主参数 + 派生** | 轮辋直径 → 扁平比 | 按规则 A 自动派生（可关开关） |
| **互相校验（警告不阻止）** | J ↔ 胎宽 | 双向校验 + 三色提示 + 一键吸附按钮，**绝不自动改** |
| **派生显示（只读）** | 外径、外径偏差、Plus 档位、Δouter、轮距变化、断面高 | — |
| **用户标定** | 翼子板基准、OE 参考值 | 一键标定 |

### 5.2 联动 1：轮辋直径 → 扁平比（Plus Sizing 守恒）

```
开关：linkPlusSizing（默认 true）

on rimInch change:
  Δn = rimInch_new − rimInch_old
  if (!linkPlusSizing) → 不改 aspect，只更新外径读数与警告
  aspect_target = round(aspect_old − 5 × Δn)
  if (aspect_target ∈ [25, 50]) → aspect = aspect_target
  else → aspect 钳制到边界 + 警告「外径偏差 X.X%，超出 ±3% 建议范围」
```

**为什么"警告不阻止"**：22" 的不合规组合是合法的创作选择（有人就要 22" 大脚），应当允许，但要明确告知代价。

**用户手动改扁平比后**：以用户最后一次设定为基准继续联动（不回滚）。

### 5.3 联动 2：J ↔ 胎宽（双向校验，**不自动改**）

```
on J change 或 tireWidth change:
  ratio = tireWidthMm / (j × 25.4)
  if (ratio > 1.32)      → 🔴 「轮辋过窄：胎壁支撑不足，过弯折胎」
  else if (ratio > 1.27) → 🟡 「超出 TRA 批准上限」
  else if (ratio > 1.15) → 🟢 「街道 / OEM 配置（胎壁微鼓）」
  else if (ratio > 1.02) → 🟢 「性能 / 赛道（方胎壁）」
  else if (ratio > 0.92) → 🟡 「轻微拉伸（HellaFlush 常见做法）」
  else                   → 🔴 「过度拉伸：脱圈 / 爆胎风险」

  同时显示该 J 值的绿灯胎宽区间（查 §4.3 表）
```

**不自动改的理由（重要产品判断）**：
- HellaFlush 玩法**就是**要 10.5J 装 225（拉伸），自动吸附会直接毁掉这个玩法
- 同一 J 值下，街道党和赛道党会选不同胎宽，不存在唯一正确解
- 提供**一键吸附按钮**「按当前 J 值推荐胎宽 → XXXmm」和「按当前胎宽推荐 J 值 → X.XJ」，把选择权交给用户

### 5.4 联动 3：ET / J / 倾角 → 位置与齐平度

```
Δouter = (j × 25.4 / 2 − et) − (j_OE × 25.4 / 2 − et_OE) + trackAdj
轮距变化 = 2 × Δouter

齐平度（轮眉高度处，必须计入倾角）：
  flushMm = ( halfTrack + Δouter + tireWidthMm/2 × cos(θ) − OD/2 × sin(|θ|) ) − fenderRef_axis
             └──────────────────────────────────────────────────────────┘
                               轮胎胎侧外缘位置
```

**当前实现缺失：齐平度没有计入倾角，也没有用胎宽。**这是"负值倾角换齐平"这个真实做法无法在预览中体现的原因。

### 5.5 联动 4：外径 → 车高

保持现有行为（`axle.position.y = R`）。新增显示：外径 mm / in + 偏差 %。

### 5.6 前后轴联动是否相同

**规则完全相同，各自独立计算。**唯一增加的是跨轴检查：

| 检查 | 阈值 | 级别 |
|---|---|---|
| 前后外径差 | ≤1.5% 🟢 / 1.5–3% 🟡 / >3% 🔴 | 影响 ABS/ESP 前后轮速差 |
| 前后齐平度一致性 | 提示性信息，不做判定 | — |

### 5.7 P2：轮毂模型的尺寸基准（**未查到确切值，标记为建议**）

**问题**：轮辋名义直径 = **胎圈座直径**（ISO 5775 / ETRTO），而 `normalizeWheel` 量出的是模型**外轮廓**直径。二者不等。

```
外缘直径 ≈ 胎圈座直径 + 2 × 法兰高
外缘宽度 ≈ J × 25.4   + 2 × 法兰厚
```

⚠️ **未查到 ETRTO J 型法兰高度的权威数值**（ETRTO 手册需付费购买；northamericanmotoring 的帖子有示意图但无具体数字）。

**建议值**：法兰高 **16mm**、法兰厚 **10mm**。量级依据：J 型法兰是"中等高度"（介于 C 最低与 K 最高之间），实际轮辋外缘比名义直径大约 5–7%。

**落地方式（避免硬编码猜测）**：暴露为可调参数，让工程师按视觉调校：

```js
const RIM_FLANGE_HEIGHT_MM = 16;  // 可调，默认建议值
const RIM_FLANGE_THICK_MM  = 10;  // 可调，默认建议值
rimOuterDia     = rimInch * 25.4 + 2 * RIM_FLANGE_HEIGHT_MM;
rimOuterWidthMm = j * 25.4       + 2 * RIM_FLANGE_THICK_MM;
```

**P2：裸辋 / 带胎总成判别**（`wheelRig.js:129` 已有相关注释，但只是绕过问题）：

```
若 measured.width > (j + 3) × 25.4  → 判定为"带胎总成"
处理：仅按直径比例缩放；或提示用户上传裸辋照片
```
依据：带胎总成的宽度约为轮辋宽的 1.2–1.4 倍，远大于 +3 英寸阈值。
