# banned-words.txt — 违禁词增量词库（可选）
#
# 说明：
#   · 本文件在 server/moderation.mjs 启动时自动加载，与代码内置词库合并。
#   · 每行一个词；以 # 开头的行是注释，会被忽略；空行忽略。
#   · 支持 "类别:词" 形式（类别仅作标注，不影响匹配），例如：curse:傻帽
#   · 匹配在「归一化」文本上进行：自动忽略大小写、空白及 * _ ~ · - 等常见分隔/混淆字符，
#     因此 傻*逼 / 沙_逼 / 沙 逼 等变体都会被命中，无需逐条列举。
#   · 部署后直接改此文件即可更新词库，无需改代码、无需重新构建镜像。
#
# 类别参考（依据《网络信息内容生态治理规定》第六/七条）：
#   curse    辱骂/脏话
#   gamble   赌博
#   drug     毒品
#   porn     色情违法活动
#   violence 暴恐
#   polity   涉政违法
#   fraud    诈骗/广告引流
#
# 下方默认仅留注释模板；如需扩充，在文件末尾按需追加即可，例如：
# curse:傻帽
# gamble:网络百家乐
# drug:合成大麻素
